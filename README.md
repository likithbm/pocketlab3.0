# 🔬 PocketLab 3.0 – Interactive Virtual STEM Laboratory

### Learn • Experiment • Explore • Innovate

**PocketLab 3.0** is an interactive virtual STEM laboratory designed to make science and mathematics education accessible, engaging, and practical for school students, especially those in rural and underserved communities.

Developed for **STEM for Impact 2026**, a 24-hour hackathon organized by Presidency Makerspace.

## 🎯 Problem Statement

Many schools, particularly in rural areas, lack access to well-equipped science laboratories, experimental equipment, and interactive learning resources.

PocketLab aims to bridge this gap by providing a digital platform where students can explore scientific concepts through virtual experiments and simulations.

## ✨ Key Features

- 🧪 Interactive STEM experiments
- ⚡ Physics simulations with adjustable parameters
- 🧬 Virtual science learning activities
- 🌐 Interactive 3D experiment visualizations
- 📚 Mathematics and chemistry learning modules
- 🧠 Experiment-based MCQ quizzes
- 🤖 AI-assisted learning support
- 📊 Student progress tracking
- 👨‍🏫 Student and teacher dashboards
- 🏆 Gamified learning and achievements
- 📱 Responsive user interface
- 📶 Offline learning support

## 🛠️ Technology Stack

## ⚙️ How It Works

Students can select STEM subjects, explore interactive experiments, adjust simulation parameters, observe results, study scientific formulas, and complete quizzes.

The platform is designed to record learning progress and provide a separate dashboard for teachers to monitor student activity.

## 🚀 Running Locally

1. Clone the GitHub repository.
2. Open the project in Visual Studio Code.
3. Open the backend folder in the terminal.
4. Install dependencies using `npm install`.
5. Start the backend using `node server.js`.
6. Open the frontend using a local development server.

The SQLite database is maintained locally and is not included in the latest repository files.
